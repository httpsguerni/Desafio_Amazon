# Desafio_Amazon

Réplica da interface do site da Amazon, desenvolvida originalmente em 2024 como desafio de front-end e posteriormente portada para Angular, com layout responsivo para desktop e mobile.

## Sobre

Projeto de estudo focado em reproduzir fielmente a experiência visual e interativa do e-commerce da Amazon: header com busca e navegação, carrinho de compras com cálculo dinâmico de total e frete, e footer institucional.

## Funcionalidades

- Header com barra de busca, informações de frete e navegação por categorias
- Carrinho de compras com preços parcelados e cálculo automático de total
- Frete condicional por região (Sudeste vs. demais estados)
- Layout responsivo (desktop, tablet e mobile)

## Stack

- Angular
- TypeScript
- CSS puro

## Deploy

Publicado automaticamente via GitHub Actions a cada push na branch `main`.
